# Walkthroughs

Follow-along tutorials. Each one is a sequence of copy-pasteable commands with
the real output beside them, so you can work through it at your own pace and
check yourself at every step.

The output in these files is captured from actual runs on a Coralboard SL. If a
command prints something different for you, that's a real difference worth
chasing, not a typo in the docs.

| # | Walkthrough | What you need |
|---|---|---|
| 1 | [Zero to first AI](01-zero-to-first-ai.md): flash the card, boot, get online over USB, classify an image and run Gemma 3 on the NPU | Coralboard SL, microSD card and reader, USB-C data cable, a Linux PC |
| 2 | [The full kit](02-full-kit.md): Wi-Fi, camera object detection and the Sense add-on's mics *(not written yet)* | Walkthrough 1, plus the Wi-Fi module, Arducam B0033 and Sense add-on |
